# Client

## 開発サーバー起動

```bash
pnpm dev
```

## ビルド

```bash
pnpm build
```

## Lint

```bash
# Lint チェック
pnpm lint

# Lint 自動修正
pnpm fix:lint
```

## テスト

```bash
# 単体テスト
pnpm test

# E2E テスト
pnpm e2e
```

## Storybook

```bash
# Storybook 起動
pnpm storybook

# Storybook ビルド
pnpm build-storybook

# Storybook テスト
pnpm test-storybook
```
